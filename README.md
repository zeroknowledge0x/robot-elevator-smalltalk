## Entry

The program writes a single UTF-8 line to `/output/entry.txt`, under 200 characters.
It uses no network, no clock, no random source and no secrets, so two runs produce
byte-identical output.

Set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`.
